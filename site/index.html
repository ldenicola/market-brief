Your preferred wave size

Ratings combine swell size and period, how directly the swell reaches each beach, wind (offshore is best), your size preference and, if set, the spot's best tide. They're computed from open-ocean forecast models, so local sandbanks and reefs aren't captured. Treat them as a guide. Surf heights are estimated wave faces. Forecast data: Open-Meteo.com (CC BY 4.0), using models from DWD, Météo-France, ECMWF and NOAA.
